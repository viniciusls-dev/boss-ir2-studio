# IR-2 Studio 0.1.0 Preview 3

This preview adds **English and Brazilian Portuguese** to the native Mac editor for the BOSS IR-2.

- Interface labels, accessibility labels, status messages, and app errors are translated.
- The app follows your Mac's preferred language by default, with English as the fallback.
- Choose **Language / Idioma** at the bottom of the sidebar to select System, English, or Português. Quit and reopen the app to apply the choice to the interface, native menus, and file dialogs.
- Your saved preset names, notes, and parameter values are preserved. Existing content is not automatically translated.

Both-channel editing, live pedal updates, local presets, read-only `.alb` inspection, light/dark appearance, and the custom Dock icon remain available.

## Download and install

Requires **Apple Silicon (M1 or later)** and **macOS 26+**. Download files with `preview.3` in their names. Open the DMG and drag the app to Applications, or extract the ZIP and move the app there. Choose one package; both contain the same app. SHA-256 checksums are included.

**This free preview is locally signed and is not notarized by Apple.** macOS may require you to authorize the first launch through Privacy & Security. See [Apple's instructions](https://support.apple.com/en-us/102445).

For pedal control, install the BOSS IR-2 driver, use USB VENDOR mode, and open **My IR-2 / Meu IR-2**. Editing starts disabled. Enable **Edit pedal / Editar pedal** to send changes.

## Limits and privacy

The app does not read/control on/bypass, update firmware, restore full backups, or load cabinet IRs. Check the physical CHECK LED for effect on/bypass.

The package includes its translation resources and is checked for local user or project paths. Personal preset libraries and backups are not included. App version: `0.1.0`, build `3`.

This is an independent project, not an official BOSS/Roland product.
