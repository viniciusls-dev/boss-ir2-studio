# IR-2 Studio 0.1.0 Preview 2

A ready-to-run Mac app for controlling a BOSS IR-2 over USB.

This release is built from the initial working baseline commit in the consolidated repository history. It replaces Preview 1 and includes the current Dock icon handling and package privacy checks.

- Read and edit both channels: Gain, Bass, Middle, Treble, Level, Ambience, and amp model.
- Receive pedal changes in real time, without periodic polling or screen reloads.
- Save, import, export, and apply two-channel presets.
- Inspect official `.alb` backups without changing them.
- Light, dark, and system appearance, with a custom app icon.
- An importable CLEAN / BRIT example preset inspired by *Someday* is available in the repository's `Presets` folder.

## Download and install

Requires **Apple Silicon (M1 or later)** and **macOS 26+**. The BOSS IR-2 driver and USB VENDOR mode are required for pedal control.

Download files with `preview.2` in their names. Open the DMG and drag the app to Applications, or extract the ZIP and move the app there. The packages contain the same app; you only need one. SHA-256 checksums are provided alongside the downloads.

**This preview is locally signed and is not notarized by Apple.** macOS may require you to authorize the first launch through Privacy & Security. See [Apple's instructions](https://support.apple.com/en-us/102445).

The interface is currently in Portuguese. Start with **Meu IR-2**, then enable **Editar pedal** to send changes. The app initially connects in read-only mode.

## Limits

The app does not read/control the pedal's on/bypass state. Check the CHECK LED and use the physical switch for bypass. Firmware updates, full backup restoration and cabinet IR loading are not included.

This is an independent project, not an official BOSS/Roland product. USB protocol and validation notes are included in the repository.

## Package privacy

Local source paths are remapped during compilation, debug records are removed before signing, and the package contents are checked for local user or project paths. Personal preset libraries and pedal backups are not included. The app version is `0.1.0`, build `2`.
